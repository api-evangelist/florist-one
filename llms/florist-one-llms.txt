# Florist One

> Florist One is a flower delivery service that fulfills florist-delivered flowers
> through a network of roughly 15,000 local florists across the United States and Canada.
> It publishes a free REST API that lets any website or application list flower and gift
> basket products, check delivery dates, manage a server-side shopping cart, price an
> order, place it, and look it up afterwards. There is no fee to use the API; Florist One
> pays the integrator a 20% commission on each sale and handles fulfillment, payment
> processing and customer service.

This file was generated by API Evangelist from the public Florist One surface on
2026-09-10. Florist One serves no llms.txt of its own (https://www.floristone.com/llms.txt
returned 404).

## Read this first

- The callable API base is `https://www.floristone.com/api/rest`. The `/api/` path is the
  marketing and documentation site, not an API host.
- Authentication is HTTP Basic with an API Key as the username and an assigned password.
  Florist One's own sample code sends the raw base64 credential in `Authorization` with no
  `Basic ` scheme prefix. An unauthenticated call returns HTTP 403 with an IIS HTML error
  page, not JSON.
- Full endpoint documentation is gated: https://www.floristone.com/api/technical-information/
  is a login form asking for an API Key and password. Code samples are released after signup.
- Money moves on `POST /flowershop/placeorder` and `POST /giftbaskets/placeorder`, a real
  florist is dispatched, and the published contract exposes no cancel, void or refund
  operation. Credits and refunds are a manual process at Florist One's sole discretion.
- There is no sandbox, no test mode, no idempotency key and no published rate limit.

## APIs

- [Florist One API](https://www.floristone.com/api/): the developer overview and portal.
- [FlowerShop API](https://www.floristone.com/api/): products, delivery dates, totals, order placement, order lookup.
- [GiftBaskets API](https://www.floristone.com/api/): gift basket products, totals, order placement.
- [ShoppingCart API](https://www.floristone.com/api/): create, read, modify and destroy a server-side cart.
- [Affiliate API](https://www.floristone.com/api/): retrieve the affiliate legal agreement.
